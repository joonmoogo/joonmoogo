## 🤖 How I build with AI

I don't use AI as autocomplete — I run it as an engineering team.

```
  1. Contract first      →  I design the shared types, store and API surface myself
  2. Parallel agents     →  5–6 agents build separate modules at once, each owning its own files
  3. Integration review  →  I relay cross-module concerns, fix contracts, merge
  4. Verify for real     →  typecheck · build · drive the app in a browser · two-tab collab tests
```

- **Agentic coding** — Claude Code multi-agent orchestration, sub-agent scoping, contract-driven parallel development
- **Automation** — scheduled agents & cron pipelines that run daily work without me (e.g. an automated research-log pipeline)
- **Ship & operate** — infra, deploys, monitoring and incident triage on real production services
